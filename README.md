## 🔗 What I'm building: Bareium

India-first link infrastructure: short links, mobile deep links, campaigns and TRAI-compliant SMS links.

- **Rust/axum** services on **GCP Cloud Run** behind a **Cloudflare Worker**, over Postgres, Redis and BigQuery
- Redis-first redirects averaging **~5 ms in production**, plus effectively-once click analytics into BigQuery
- Live payments, with **~1,100 tests** across 7 suites, mutation testing and fuzzing
- Published tools for developers and AI agents:
  - [`@bareium/mcp`](https://www.npmjs.com/package/@bareium/mcp): MCP server, so agents like Claude and Cursor can manage links
  - [`@bareium/cli`](https://www.npmjs.com/package/@bareium/cli): command-line client
  - [Chrome extension](https://chromewebstore.google.com/detail/bareium-%E2%80%94-url-shortener/clcaajebpfddcfhoanoikalkldgmlmfe)

The Bareium code is private; the products above are public.
